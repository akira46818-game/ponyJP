# にじのはしを かこう

幼児〜小学校低学年向けの、時間制限のない橋のお絵かきゲーム。静的なHTML/CSS/JavaScriptで動き、ChatGPTや外部APIへの接続は不要です。

- 指・ペン・マウスで花から旗へ橋を描き、「わたってみよう」で選んだキャラクターが渡ります。逆方向に描いても遊べます。
- ルミナ、フレア、アクア、ミュウミュウ、テラ、ストームの既存の透明画像を共有します。
- なみなみ・S字・ループ・森のくねくね道・ハート・お城への二重ループの6コース。上のボタンから好きな順で遊べます。全部の星を通る橋を描くと、キャラクターが星を集めながら渡ります。自分で別の形に描いても遊べ、線の交差や逆戻りも可能です。
- 岸の近くで始めたり終えたりした線は補正し、星は半径54の範囲を通れば取得できます。岩は線分全体で判定し、重なったときは描き直しを案内します。落下・ゲームオーバーはありません。
- お手本の点線表示と「おてほんの はしを つかう」があり、ドラッグが難しい場合もボタンで遊べます。
- 音は初期OFF。画面が隠れたときは移動が止まり、音声は終了します。視差や点滅は使わず、動きを減らす設定に対応します。
- 保存先は `ponyland-rainbow-bridge-v1`。描画途中は保存せず、有効な橋・ステージ達成・選んだキャラクターを保存します。
- 6ステージ達成で既存の無料ガチャ券を1枚発行。`rainbow-bridge:<roundId>:day:1` により再読み込み・再試行で同じ券を再発行しません。既存ガチャと同じブラウザ内保存方式です。

検証: `node tests/rainbow-bridge.mjs`。全コースの正逆方向・星の取得・交差・岩との接触・コース選択・旧データの復元を確認します。ブラウザでは描画・お手本・曲がり道の移動・6コース達成・スマートフォン表示を確認します。
