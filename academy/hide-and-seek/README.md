# ポニーランドのかくれんぼ

幼児〜小学校低学年向けの、隠れ場所をタップして仲間を見つけるゲームです。静的なHTML/CSS/JavaScriptで動作し、ChatGPTや外部APIを使いません。

- お花畑・おもちゃ部屋・星の森の3つの場所。それぞれ9か所に6人が隠れます。ルミナ・フレア・アクア・ミュウミュウ・テラ・ストームの既存の透明画像を利用します。
- 隠れ場所はラウンドごとにシャッフルして保存します。ページの再読み込み・モード切り替え・場所の切り替えでは変わりません。
- 顔が見えやすい「やさしい」と、深く隠れる「ちょうせん」。ヒントは未発見の仲間がいる場所を案内します。時間制限・失敗ペナルティはありません。キーボードでも各場所を調べられます。
- 3か所で全員を見つけると無料ガチャ券1枚。既存のMarketGiftsを使い、`hide-and-seek:<roundId>:day:1` で再読み込み・連打・保存の再試行による二重発行を防ぎます。保存できなければ再試行ボタンを表示します。
- セーブキーは `ponyland-hide-and-seek-v1`。ガチャページのバックアップ対象にも追加しています。
- 音声読み上げ・効果音は初期OFF。画面を離れると音を止めます。動きを減らす設定に対応します。

検証: `node tests/hide-and-seek.mjs` と `node tests/market-gifts.cjs`。ブラウザーでは発見、空の場所、ヒント、モード切り替え、再読み込み、3か所の達成、無料券保存、スマートフォン表示を確認します。
